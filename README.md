### 📱 Android Text Editor

**Kotlin Code Editor for Android**

A mobile text and code editor built using **Kotlin, Jetpack Compose and Material3**.

Alongside standard editing features, the application supports **Kotlin syntax highlighting and ADB-based compiler integration**, allowing Kotlin files to be compiled using a desktop compiler while returning errors directly to the editor.

**Tech**

`Kotlin` `Jetpack Compose` `Material3` `Android` `ADB`

**Key Highlights**

- 📄 File creation, opening & saving
- ↩️ Undo / redo editing
- 🔎 Advanced find & replace
- 🎨 Kotlin syntax highlighting
- ⚡ ADB compiler integration
- 🧪 Compilation error reporting
